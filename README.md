# Xing Long · Bar Cafeteria · Terrassa

One-page website for Xing Long, C/ Miquel Vives 28, 08222 Terrassa.

- `index.html` — the whole site (Catalan, Spanish, English, Chinese)
- `carta.json` — the menu. To change a price, edit the `preu` number (use a dot: `5.70`), commit, done.
- `img/` — photos

Hosted with GitHub Pages.
